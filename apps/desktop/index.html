Voxium — Privacy-First Real-Time Communication Platform

Privacy-first voice, video, chat and screen sharing for communities. Self-hostable, end-to-end encrypted direct messages, no phone number required — and no ads, tracking or data collection, ever.

Open Voxium in your browser · Sign in · Source code on GitHub

Why communities choose Voxium

  • Crystal-clear server voice channels powered by an SFU, with ML noise suppression (RNNoise)
  • Real-time text chat with reactions, replies, mentions and file sharing
  • End-to-end encrypted direct messages and private calls
  • Screen sharing with system audio
  • Custom themes, roles and fine-grained permissions
  • 100% source-available and self-hostable — audit every line; your server, your data
  • Lightweight desktop app (Tauri, ~10 MB) for Windows, macOS and Linux, plus the browser

Fair pricing, no ads

Voxium is free for individuals and small communities, and self-hosting is always free. Large communities on the hosted service pay for the server resources they actually consume — never to unlock features. No ads, no telemetry, no trackers, no third-party services.
